
# 模块三 · 连接器与技能生态

## 第 12 课 · 连接器：打通邮箱 / 文档 / 微信 / Notion

### 🎯 本课目标
学会开启"连接器"，让 WorkBuddy 直接操作你的邮箱、腾讯文档、飞书、微信、Notion、GitHub 等外部服务——不用来回切软件。

### 📖 知识点：连接器 = 连外部软件的"插头"
开启后，你就能用一句话操作那些平台。
**开启方法**：设置 → 连接器 → 找到你要的（如 QQ 邮箱）→ 点开启 → 按提示授权。
> ⚠️ 铁律：**用之前必须先开连接器**。没开它没权限，会做不了。

**常见连接器和用法：**

| 连接器 | 一句话能干嘛 |
|------|------|
| QQ 邮箱 | 「获取最新 10 封邮件，列发件人、主题、摘要」 |
| 腾讯文档 | 「创建项目排期表，含任务/负责人/时间/状态 5 列，预填 10 行」 |
| 金山文档 | 「在『客户案例』文件夹批量创建 50 个文档，命名客户001~050」 |
| 飞书 | 「读飞书『需求文档』下所有文档标题，整理成目录」 |
| Notion | 「搜 Notion 里含『重装系统』的页面，按最近编辑排序」 |
| GitHub | 「列出仓库 my-project 最近 10 个未关闭 Issue，按优先级排」 |
| Canva 可画 | 「做一张公众号封面，900×383，主题『AI 效率工具』，简约清新」 |
| 腾讯问卷 | 「创建满意度问卷，5 道单选+2 道简答，主题产品体验」 |
| ima 知识库 | 「从 ima 搜『产品方法论』的笔记」 |

### ✋ 实操案例：跨平台一条龙
开启 ima + 腾讯文档两个连接器后：
```
1. 从我的 ima 知识库搜关于「产品方法论」的笔记
2. 整理成结构化文档
3. 保存到腾讯文档，命名「产品方法论整理」
```
一句话跨三个平台完成 检索 → 整理 → 创建。

### 💡 微信集成（提醒神器）
设置 → Claw 设置 → 微信助手集成，扫码后 WorkBuddy 的消息能同步到你微信。适合做提醒："提醒我下午 3 点取快递"。
> ⚠️ 注意：电脑需一直开机；你在电脑发的消息不会同步回微信。

### 🚧 边界
连接器有**写入权限**（能建文档、发邮件）。涉及"外发"（发邮件给客户、写入 CRM）的操作，**默认让它先出草稿，你确认再发**——别让它自动外发未经确认的内容。

### 📝 课后作业
开启 QQ 邮箱连接器，汇总今天未读邮件。体验"不打开邮箱也能收邮件"。

## 第 13 课 · 技能 Skill：给它装外挂（安装 + 实战）

### 🎯 本课目标
搞懂"技能 Skill"是什么，安装官方技能，解锁下视频、发公众号、生成 PDF 等专项能力。

### 📖 知识点：Skill vs 连接器
- **连接器**：连"你已有的账号平台"（你的邮箱、你的文档）。
- **技能 Skill**：装"某种专门能力"（比如"会下抖音视频"这个本领）。

**官方技能举例（在设置/技能市场安装）：**

| 技能 | 能干嘛 | 提示词示例 |
|------|------|------|
| 抖音批量下载 | 下载某账号全部视频 | 「下载抖音账号 XXX 主页全部视频到本地」 |
| Wechat Publisher | 一键发文到公众号草稿箱 | 「把 my-article.md 发到公众号草稿箱，封面用第一张图」 |
| PDF 文档生成 | 从文本生成精美 PDF | 「把以下内容生成商务风 PDF，含封面/目录/页码」 |
| 公众号爆款查询 | 搜全网 10w+ 找灵感 | 「搜『AI 工具』相关 10w+ 爆款，列标题+公众号+时间」 |
| 浏览器自动化 | 网页截图/填表/抓数据 | 「抓豆瓣电影 Top250 名称/评分/导演，整理成表格」 |
| 公众号文案创作 | 生成长文，指定风格 | 「以『AI 办公效率翻倍』为题写 2000 字，口语化」 |
| stock-advisor | 股票技术+基本面分析 | 「分析这只票的 K 线和财报，给综合评级」 |

> 附录 B 有更完整的技能清单（含资讯类、事实核查类）。

### ✋ 实操案例：内容创作一条龙
装好「公众号文案创作」+「Canva」+「Wechat Publisher」后：
```
1. 以「5 个提效 AI 工具」为主题写一篇 1500 字公众号文，轻松口语风
2. 用 Canva 配一张封面图，主题同上，简约清新
3. 把文章发到我的公众号草稿箱，用刚才的封面
```

### 💡 进阶了解
高手会把一堆技能放中央文件夹，用"目录软链接"批量挂给 WorkBuddy。你现在只要知道：**技能可以不断加，加得越多它越全能。** 需要什么本事，去技能市场找找。

### 🚧 边界
下载类技能（抖音、视频）**要遵守平台条款、版权和合理使用**。目的是学习结构、做参考，不是搬运。

### 📝 课后作业
逛一遍技能市场，找 1 个和你工作最相关的技能，安装并试用一次。

## 第 14 课 · 打造自己的 Skill：把书和视频蒸馏成能力

### 🎯 本课目标
从"用现成技能"升级到"造自己的技能"——把一本书、一个教程视频、一套你的方法论，蒸馏成 WorkBuddy 可反复执行的 Skill。这是 L3 的分水岭。

### 📖 知识点：为什么要自造 Skill
现成技能解决通用动作。但你的**独门方法论**（比如你写周报的固定框架、你审合同的检查清单、你做竞品分析的评分表）没人替你封装。把它变成 Skill，就等于**把"你怎么做这件事"固化下来，以后一句话触发，每次都按你的标准来**。

**一个 Skill 通常包含三样东西：**
1. **触发场景**：什么时候用它（"当我要写竞品分析报告时"）。
2. **方法论/步骤**：按什么框架、什么顺序做（你的 SOP）。
3. **输出模板**：产物长什么样（固定的表格、章节、字段）。

### ✋ 实操思路：把一份"方法论"蒸馏成 Skill
**第一步 · 喂原料**（把书/视频稿/你的 SOP 拖进工作区）：
```
这是我做竞品分析的方法论文档（附件）。请你把它蒸馏成一个
可复用的工作流：1. 什么情况触发  2. 分几步、每步做什么
3. 最终输出的固定模板（章节+表格字段）。先给我看这个蒸馏结果。
```
**第二步 · 固化成技能**：确认蒸馏结果后，按 WorkBuddy 技能市场/设置里的"创建技能"流程，把这套框架保存成你的专属 Skill（也可创建为"专家"，见第 19 课）。
**第三步 · 测试**：新开一个任务触发它，喂一个真实竞品，看是否严格按你的模板产出。连续 3 次达标 = 这个 Skill 可用了。

### 💡 小技巧
- **从窄开始**：先造一个只做一件事的小技能（如"生成标准周报"），跑顺了再扩。
- **模板越具体越稳**：把输出模板的字段、章节写死，产出一致性会大幅提升。

### 📝 课后作业
挑一件你每周都做、且有固定套路的活，把套路写成"触发+步骤+模板"，蒸馏成一个 Skill，测试 3 次。

## 第 15 课 · 知识系统：ima / Obsidian / 收藏再利用

### 🎯 本课目标
解决一个普遍痛点：**收藏 = 存了就忘**。让 WorkBuddy 把你散落在各处的笔记、收藏、文档变成"能再次用起来"的知识系统。

### 📖 知识点：收藏不是知识管理
"能再次用起来才是。" WorkBuddy 能连接 ima 知识库、Obsidian、WPS、腾讯/飞书文档，把碎片信息**检索出来 → 结构化 → 关联 → 再产出**。

一个个人知识工作流通常是：
> 移动端随手捕捉（ima/微信）→ 定期归集 → 打标签分类 → 需要时检索 → 组装成新产物（报告/文章/方案）→ 来源"体检"（哪些信息过期了）

### ✋ 实操案例

**案例 A · 把散落笔记变成一篇文章**
```
从我的 Obsidian 里搜所有含「Agent 设计」的笔记，
去重后按主题聚类，帮我组织成一篇 2000 字文章的提纲，
标出每个观点来自哪条笔记（可溯源）。
```

**案例 B · 知识库体检**
```
检查我 ima 知识库里「AI 工具」标签下的笔记，
标出哪些信息可能已过期（涉及具体版本号、价格、榜单的），
列出需要更新的清单。
```

**案例 C · 移动捕捉 + 定期整理**
配合微信助手：随手把想法发给 WorkBuddy，设一个每周日的自动任务（见第 16 课），"把本周捕捉的碎片笔记归集分类，存入 Obsidian"。

### 💡 小技巧
让它在整理时**始终保留来源**（哪条结论来自哪个文件），这样你的知识系统才可信、可追溯，而不是又一堆"AI 生成的看起来对的话"。

### 📝 课后作业
选一个你的笔记库（ima/Obsidian/文档都行），让它做一次"知识库体检"，看看有多少收藏其实早就该更新了。

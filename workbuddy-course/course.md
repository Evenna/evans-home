## 第 1 课 · 认识 WorkBuddy：它到底是什么

### 🎯 本课目标
用一句话说清 WorkBuddy 是什么，以及它和你平时用的 ChatGPT / 文心一言有什么本质区别。

### 📖 知识点

**WorkBuddy 是腾讯出的「AI 办公智能体」。** 关键词是"智能体"（Agent）——它不只会聊天，它会**动手干活**：读你的文件、写文档、做 PPT、跑数据、上网查资料，最后交给你一个能直接用的成品。

打个比方：
- 普通 AI 聊天 = 一个**顾问**，你问它问题，它给你建议，但活还得你自己干。
- WorkBuddy = 一个**助理**，你交代任务，它自己拆步骤、找资料、动手做，做完把成品递到你手上。

**三个最直观的区别：**

| 对比 | 普通 AI 对话 | WorkBuddy |
|------|------|------|
| 它能干嘛 | 只能回答、给建议 | 真的帮你执行任务 |
| 文件操作 | 你得自己复制粘贴 | 它直接读写你电脑的文件 |
| 交付物 | 一段文字 | 可下载的 Word/PPT/表格/网页 |

**举几个它能干的活（先感受一下）：**
- 「帮我生成本周工作周报」→ 直接出一份排版好的周报
- 「分析这份销售数据并出图表」→ 读 Excel、算数据、出柱状图，打包成报告
- 「把这 100 张图片按日期重命名」→ 几秒钟批量搞定
- 「根据这份大纲做一份 10 页 PPT」→ 直接产出 .pptx 文件

### ✋ 动手感受
先不用装软件。打开官网 **www.workbuddy.cn**，看首页的演示视频，感受一下"一句话出成品"是什么体验。心里有个概念：**我以后交给它的是"任务"，不是"问题"。**

### 💡 一句话总结
> ChatGPT 告诉你怎么做，WorkBuddy 直接替你做完。

### 📝 课后作业
想 3 件你平时上班最烦、最重复的活（比如整理表格、写日报、改文件名），记下来——后面几节课我们挨个用 WorkBuddy 干掉它们。

## 第 2 课 · 下载、安装、登录

### 🎯 本课目标
5 分钟内把 WorkBuddy 装好，完成登录，领到新手积分。

### 📖 知识点 + ✋ 实操步骤

**第 1 步：下载**
打开官网 **www.workbuddy.cn**，点首页的「下载」按钮，选对应你电脑的版本（Windows / Mac）。下载完双击安装包，一路「下一步」装完即可。

**第 2 步：登录**
首次打开需要**微信扫码登录**，扫码后手机上做个验证就进去了。

**第 3 步：领新手积分**
新用户会**赠送 2500 积分**（基础体验包，有效期 30 天）。积分是用来做任务的"油费"——大部分文字任务花得很少，生成图片/视频才花得多（后面会讲）。

**关于收费（了解即可，新手先用免费额度）：**
- 标准版：约 99 元/月起
- 高级版：约 199 元/月起
- 旗舰版：约 999 元/月起

> ⚠️ 价格和活动会变，以官网为准。新手 2500 积分足够你跑完本课程大部分练习。

**进阶（可跳过）：接入自己的模型**
如果你有自己的 API（比如公司给的 OpenAI 兼容接口），可以在设置里接入。**注意目前只支持 OpenAI 兼容协议的 API**。小白阶段完全不用管这个，用它自带的就行。

### 📝 课后作业
装好软件、扫码登录、确认自己账户里有积分余额。截图记录你的积分数，方便后面观察消耗。

## 第 3 课 · 界面导览：看懂三大区域

### 🎯 本课目标
打开软件不发懵——认清界面三大区域，知道东西都在哪。

### 📖 知识点
打开 WorkBuddy 后，界面从左到右分成**三大块**：

**① 侧边栏（左侧）——你的任务清单**
所有做过的任务都按文件夹列在这。可以搜索、按状态筛选。底部是你的头像和「设置」入口（连接器、技能都在设置里开）。

**② 对话区（中间）——干活的地方**
这是核心。顶部是任务标题，中间是你和 AI 的对话记录，底部是输入框——**可以直接把文件拖进去**上传。你在这里下达任务。

**③ 结果区（右侧）——拿成品的地方**
这是 WorkBuddy 和普通聊天最不一样的地方！它有 4 个小标签：
- **产物**：看生成的文档 / PPT
- **全部文件**：列出所有产出的文件
- **变更**：显示文件被改了哪些地方
- **预览**：实时预览网页 / PPT 效果

> 💡 记住：右侧结果区 = 你的**成品仓库**。你不光能看到 AI 的回复，还能直接下载、使用它做出来的文件。这就是"智能体"和"聊天机器人"的分水岭。

### ✋ 动手操作
1. 随便发一句：「帮我写一段 100 字的公司午餐会通知」
2. 观察：中间对话区出现回复，右侧结果区出现产物
3. 点右侧「产物」，看看能不能下载

### 📝 课后作业
把界面三个区域的名字和作用，用你自己的话讲给自己听一遍。熟悉「拖文件到输入框」这个动作。

## 第 4 课 · 三种工作模式：Craft / Plan / Ask

### 🎯 本课目标
搞懂三种模式分别是什么，什么时候该切哪种——这是用好 WorkBuddy 的关键开关。

### 📖 知识点
WorkBuddy 顶部有个模式切换，共三种：

| 模式 | 一句话理解 | 什么时候用 |
|------|------|------|
| **Craft（你说我做）** | 立即行动，直接开干 | 日常任务首选：写文档、做 PPT、分析数据 |
| **Plan（先想后做）** | 先给你方案，你点确认它再动手 | 复杂项目：建网站、大改动、方案没想好时 |
| **Ask（只聊不动手）** | 只回答，不碰你的文件 | 只想咨询、对比方案、问问题时 |

**新手记住一句话：90% 的日常活用 Craft 就够了。**

- 简单活（写个通知、做个表）→ 直接 **Craft**，它立刻做。
- 复杂活（搭个网站、整理一个大项目）→ 切 **Plan**，让它先出计划，你看没问题再让它执行，避免方向跑偏。
- 只是想问问、不想它乱动我文件 → 切 **Ask**，安全地聊。

### ✋ 动手对比
同一个需求，用两种模式各试一次，感受区别：
- **Craft 模式**发：「做一份 5 页的读书分享 PPT，主题《原子习惯》」→ 它直接开做
- **Plan 模式**发同样的话 → 它会先列个计划（几页、每页讲啥），等你确认

你会立刻明白：越复杂的活，越值得先用 Plan 让它"想清楚再动手"。

### 💡 避坑提示
新手最常见的错误：一上来对着超复杂需求用 Craft，结果做出来方向全错、还白花积分。**复杂任务先 Plan，是省时省钱的第一原则。**

### 📝 课后作业
把你第 1 课记下的 3 件烦人活，各判断一下：该用 Craft 还是 Plan？写下你的判断理由。

## 第 5 课 · 办公三件套：一句话出 Word / Excel / PPT

### 🎯 本课目标
用一句话让 WorkBuddy 生成周报（Word）、表格（Excel）、演示文稿（PPT），并从右侧结果区下载。

### 📖 知识点
这是职场人用得最多的功能。诀窍在于**把需求说清楚**。有个万能公式（第 11 课会细讲）：

> **背景 + 目标 + 具体要求 + 输出格式**

❌ 差的说法：「帮我写个周报」（它不知道你干了啥，只能瞎编）
✅ 好的说法：「我是运营，本周做了 3 场直播、写了 5 篇推文、参加了选题会。帮我生成本周周报，Word 格式，分『本周完成』『下周计划』『问题与风险』三部分。」

### ✋ 实操案例

**案例 A：生成周报（Word）**
```
我是市场部专员，本周完成了：新品发布会筹备、2 篇公众号推文、
对接了 3 家媒体。帮我写一份本周工作周报，Word 格式，
分「本周完成」「下周计划」「需要支持」三个板块，语气正式。
```

**案例 B：生成排期表（Excel）**
```
帮我做一份项目排期表，Excel 格式，包含这几列：
任务名称、负责人、开始时间、结束时间、状态。预填 10 行示例数据。
```

**案例 C：从大纲生成 PPT**
```
根据以下大纲做一份 15 页 PPT，风格简洁商务，配色深蓝+白：
1. 封面：产品名称+Logo
2. 目录
3-5. 行业痛点（3页）
6-9. 产品核心功能（4页，每页一个功能）
10-12. 竞品对比（3页）
13. 商业模式  14. 团队介绍  15. 联系方式
```
它会自动排版、配图、统一风格，最后在右侧产出一个可下载的 **.pptx** 文件。

### 💡 小技巧：分步迭代，别一次求完美
做 PPT 建议这样：**先让它出框架 → 你确认结构 → 再生成完整 PPT → 最后微调风格**。比一次性丢一大堆要求效果好得多。

### 📝 课后作业
用案例 A 的模板，把「本周完成」换成你真实的工作，生成一份自己的周报并下载。

## 第 6 课 · 数据分析与可视化：上传 Excel 自动出报告

### 🎯 本课目标
把一份 Excel 数据丢给它，让它自动清洗、算汇总、出图表，产出一份带交互图表的分析报告。

### 📖 知识点
你不需要会 Excel 函数、不需要会画图。只要**把文件拖进对话框**，用大白话说你想看什么，它全自动完成：读取 → 清洗 → 计算 → 画图 → 生成报告。

### ✋ 实操案例

**案例：销售数据分析**
1. 把你的 Excel（假设有：日期、产品、区域、销售额 等列）拖进对话框
2. 输入：
```
分析这份销售数据，按月汇总各产品线的销售额，
生成柱状图和趋势折线图，找出销售额 Top 5 的区域，
最后输出一份包含图表的分析报告（HTML 格式）。
```
3. 等不到 1 分钟，右侧结果区出现一个可预览的 **HTML 报告**，里面有交互式图表。

**你还可以让它做的分析：**
- 「找出这份数据里的异常值和下降最快的产品」
- 「按季度对比，用一段话总结趋势给我」
- 「把结论做成 3 页 PPT，给领导汇报用」

### 💡 小技巧
- 数据里如果有你看不懂的列，可以先问它：「这份数据有哪些字段？帮我解释一下每列是什么」（用 Ask 模式）。
- 报告出来后不满意，直接追一句「图表颜色换成暖色系」「加一段执行摘要」，它会在原报告上改。

### 📝 课后作业
找一份你手头的真实数据（销售、考勤、账单都行），让它出一份分析报告。体验"不用会 Excel 也能做数据分析"。

## 第 7 课 · 批量处理文件：100 个文件几秒搞定

### 🎯 本课目标
让 WorkBuddy 批量重命名、归类、整理你电脑里的文件——那些手动做要半天的杂活。

### 📖 知识点
WorkBuddy 能**读写你授权的本地文件夹**。所以那些"重复 100 遍的机械操作"，一句话就能交给它。

> ⚠️ 安全提示：它只能操作你**授权**的文件夹。第一次操作某个目录时，注意看它的提示，确认路径没错再放行。

### ✋ 实操案例

**案例 A：批量重命名图片**
```
读取 D:\Photos\2026 目录下的所有图片，按拍摄日期重命名，
格式为 20260601_153000.jpg，然后按月份归类到子文件夹（如 2026-06/）。
```
它会读每张图的 EXIF 拍摄信息，批量改名+分类，最后给你一份处理日志。

**案例 B：整理下载文件夹**
```
整理我的下载文件夹，把文件按类型分到不同子文件夹：
文档类放 Docs、图片放 Images、安装包放 Installers、压缩包放 Archives。
```

**案例 C：批量转换 / 提取**
```
把这个文件夹里所有 Word 文档的标题提取出来，汇总成一个 Excel 清单，
包含：文件名、标题、字数、修改日期。
```

### 💡 小技巧
- 拿不准会不会误删？先用 **Plan 模式**让它列出"打算怎么操作"，你确认后再执行。
- 重要文件先备份一份，养成习惯。

### 📝 课后作业
挑一个你电脑里最乱的文件夹（下载夹通常是重灾区），让它帮你整理归类一次。

## 第 8 课 · 连接器：打通邮箱、文档、微信

### 🎯 本课目标
学会开启"连接器"，让 WorkBuddy 直接操作你的邮箱、腾讯文档、飞书、微信等外部服务。

### 📖 知识点
**连接器 = 让 WorkBuddy 连上外部软件的插头。** 开启后，你就能用一句话操作那些平台，不用来回切软件。

**开启方法：** 设置 → 连接器 → 找到你要的（比如 QQ 邮箱）→ 点开启 → 按提示授权。

> ⚠️ 铁律：**用之前必须先开连接器**。没开的话它没权限，会做不了。

**常见连接器和用法示例：**

| 连接器 | 一句话能干嘛 |
|------|------|
| QQ 邮箱 | 「获取我邮箱最新 10 封邮件，列出发件人、主题、摘要」 |
| 腾讯文档 | 「创建一份项目排期表，含任务/负责人/时间/状态 5 列，预填 10 行」 |
| 金山文档 | 「在『客户案例』文件夹批量创建 50 个文档，命名客户001~050」 |
| 飞书 | 「读取我飞书『需求文档』文件夹下所有文档标题，整理成目录」 |
| Notion | 「搜索我 Notion 里含『重装系统』的页面，按最近编辑排序」 |
| GitHub | 「列出我仓库 my-project 最近 10 个未关闭 Issue，按优先级排」 |
| Canva 可画 | 「做一张公众号封面，900×383，主题『AI 效率工具』，简约清新」 |
| 腾讯问卷 | 「创建一份满意度问卷，5 道单选+2 道简答，主题产品体验」 |

### ✋ 实操案例：跨平台一条龙
开启 ima 知识库 + 腾讯文档两个连接器后：
```
1. 从我的 ima 知识库搜索关于「产品方法论」的笔记
2. 整理成一份结构化文档
3. 保存到我的腾讯文档，命名「产品方法论整理」
```
一句话跨三个平台完成检索→整理→创建。

### 💡 微信集成（提醒神器）
在 设置 → Claw 设置 → 微信助手集成 里扫码，之后 WorkBuddy 的消息能同步到你微信。适合做提醒，比如「提醒我下午 3 点取快递」。
> ⚠️ 注意：电脑需一直开机；你在电脑发的消息不会同步回微信。

### 📝 课后作业
开启 QQ 邮箱连接器，让它帮你汇总今天的未读邮件。体验"不打开邮箱也能收邮件"。

## 第 9 课 · 技能 Skill：给 WorkBuddy 装外挂

### 🎯 本课目标
搞懂"技能 Skill"是什么，学会安装官方技能，解锁下视频、发公众号、生成 PDF 等专项能力。

### 📖 知识点
如果说"连接器"是连接外部平台的插头，那"技能 Skill"就是给 WorkBuddy **装的一个个专项外挂**——每个技能让它多会一样本事。

**和连接器的区别（小白理解版）：**
- 连接器：连"你已有的账号平台"（你的邮箱、你的文档）
- 技能：装"某种专门能力"（比如"会下抖音视频"这个本领）

**官方技能举例（在设置/技能市场里安装）：**

| 技能 | 能干嘛 | 提示词示例 |
|------|------|------|
| 抖音批量下载 | 下载某账号全部视频 | 「下载抖音账号 XXX 主页全部视频到本地目录」 |
| Wechat Publisher | 一键发文到公众号草稿箱 | 「把 my-article.md 发到我公众号草稿箱，封面用第一张图」 |
| PDF 文档生成 | 从文本生成精美 PDF | 「把以下内容生成商务风 PDF，含封面/目录/页码」 |
| QQ 邮箱 | 收发邮件 | 「获取最近 5 封未读邮件，有附件就下载」 |
| 公众号爆款查询 | 搜全网 10w+ 文章找灵感 | 「搜『AI 工具』相关 10w+ 爆款，列标题+公众号+时间」 |
| 浏览器自动化 | 网页截图/填表/抓数据 | 「抓豆瓣电影 Top250 名称/评分/导演，整理成表格」 |
| 公众号文案创作 | 生成长文，指定风格 | 「以『AI 办公效率翻倍』为题写 2000 字，口语化」 |

### ✋ 实操案例：内容创作一条龙
装好「公众号文案创作」+「Canva」+「Wechat Publisher」后：
```
1. 以「5 个提效 AI 工具」为主题写一篇 1500 字公众号文，轻松口语风
2. 用 Canva 配一张封面图，主题同上，简约清新
3. 把文章发到我的公众号草稿箱，用刚才的封面
```

### 💡 进阶了解（小白可跳过）
高手会把一堆技能放中央文件夹，用"目录软链接"批量挂给 WorkBuddy。你现在只要知道：**技能可以不断加，加得越多它越全能。** 需要什么本事，去技能市场找找有没有现成的。

### 📝 课后作业
逛一遍技能市场，找到 1 个和你工作最相关的技能，安装并试用一次。

## 第 10 课 · 自动化任务：让它自己定时干活

### 🎯 本课目标
设置一个"定时自动执行"的任务，比如每天早上自动汇总邮件、发日报，全程无需动手。

### 📖 知识点
WorkBuddy 能创建**定时/周期任务**——设好时间规则，到点自动跑。适合日报、周报、定时提醒、定期巡检这类"每天都要做一遍"的事。

> ⚠️ 关键限制：自动任务执行时，**你的电脑必须开着机**（它在你本机跑）。

### ✋ 实操案例

**案例 A：每日邮件晨报**
```
创建一个自动化任务：
- 每天早上 9:00 执行
- 获取我邮箱过去 24 小时的邮件
- 按重要程度分类汇总（发件人、主题、摘要）
- 通过微信助手把汇总发给我
```
（需先开启邮箱连接器 + 微信助手集成）

**案例 B：每周自动周报草稿**
```
每周五 17:00 自动执行：
读取我这周在腾讯文档「工作日志」里的记录，
生成一份周报草稿，保存到腾讯文档「周报」文件夹。
```

**案例 C：定时提醒**
```
每个工作日下午 6 点提醒我：填今天的工时表。
```

### 💡 小技巧
- 先手动跑一次，确认结果满意，再设成自动化——避免定时跑出一堆错的。
- 自动任务可靠性依赖：电脑开机 + 连接器保持授权 + 网络正常。重要任务多留意几天。

### 📝 课后作业
设置一个属于你的每日自动任务（晨报、提醒、日报都行），观察它第二天有没有准时执行。

## 第 11 课 · 提示词心法 + 记忆系统

### 🎯 本课目标
掌握"让 WorkBuddy 一次做对"的提问公式，学会用记忆系统让它记住你的偏好。

### 📖 知识点一：万能提示词公式
好指令和坏指令，效果差十倍。记住这个公式：

> **背景 + 目标 + 具体要求 + 输出格式**

- **背景**：你是谁、在什么情况下（"我是前端开发，本周…"）
- **目标**：你想要什么（"生成周报"）
- **具体要求**：细节约束（"分三个板块""语气正式""2000 字"）
- **输出格式**：要什么形式（"Word""Markdown""15 页 PPT"）

❌ 差：「帮我写个周报」
✅ 好：「我是前端开发，本周完成了登录模块重构和 3 个 Bug 修复，参加了需求评审会。帮我生成本周工作周报，Markdown 格式，分『本周完成』『下周计划』『风险与问题』三个板块。」

### 📖 知识点二：4 个提效习惯
1. **复杂任务先 Plan**：让它先出方案，确认后再执行，避免跑偏白花积分。
2. **分步迭代，别求一步到位**：先出初版 → 追问细化。做 PPT 尤其要这样。
3. **同一任务里持续对话**：它会累积上下文，不用每次重复背景。
4. **外部服务先连再用**：涉及邮箱/文档/Notion，先在设置里开连接器。

### 📖 知识点三：记忆系统（让它记住你）
WorkBuddy 有三层记忆，能记住你的偏好和项目信息：

| 层级 | 作用 |
|------|------|
| 云端记忆 | 自动学习你的长期习惯画像 |
| 用户级记忆 | 跨所有项目的长期偏好（如"我喜欢深色主题""周报要正式"） |
| 工作区记忆 | 当前项目的专属笔记和进度 |

**用法超简单**：直接对它说——
```
记住：我是做跨境电商运营的，以后写文案默认用小红书风格，
数据报告默认要执行摘要+图表。
```
它会自动记下来，以后不用每次重复交代。

### 📝 课后作业
把你最常做的一个任务（比如写周报），用"万能公式"重写一遍指令，对比效果。再教它记住 2 条你的工作偏好。

## 第 12 课 · 综合实战 + 避坑清单

### 🎯 本课目标
独立完成一个从头到尾的完整项目，并记住新手最容易踩的坑。

### ✋ 综合实战：给自己做一个"个人作品集网站"
用 **Plan 模式**发：
```
帮我搭一个个人作品集网站，技术栈 React + TailwindCSS：
- 首页：个人介绍 + 技能标签
- 项目页：卡片布局，可点开看详情
- 联系页：表单（姓名、邮箱、留言）
- 响应式，适配手机
- 部署到本地预览
```
它会先出开发计划（项目结构、文件清单、步骤），你确认后，它自动建项目、写代码、装依赖、启服务，最后在右侧给你可预览的网页。**全程你只需要看和确认。**

### ✋ 其它值得一试的综合任务
- **深度调研报告**：「调研 2026 年国内 AI 编程助手市场，含玩家对比/技术趋势/市场规模，输出 3000 字 Markdown 报告带对比表」（用 Plan 模式，它会联网搜集再整合）
- **多模态内容**：「生成一张小红书封面图 + 3 张配图 + 一段 5 秒动态视频」（注意：图片约 5-10 积分/张，视频约 50-100 积分/段）

### ⚠️ 新手避坑清单（收藏级）
1. **复杂任务不用 Plan** → 方向跑偏、白花积分。复杂活先出方案。
2. **需求说得太简单** → 用"背景+目标+要求+格式"公式补全。
3. **忘了开连接器就让它操作外部平台** → 会失败。先去设置开。
4. **一次性丢巨多要求** → 拆成分步迭代，先框架后细节。
5. **批量删改文件不先备份/不看 Plan** → 有误操作风险，重要文件先备份。
6. **生成图片/视频不看积分** → 很费积分，先看余额。
7. **自动化任务时关了电脑** → 任务不会执行，本机必须开机。
8. **不用记忆功能，每次重复交代身份** → 教它记住你的偏好，一劳永逸。

到这里，你已经能用 WorkBuddy 完成：写文档、做 PPT、分析数据、批量处理文件、连接邮箱文档、装技能、设自动化、搭网站。**从"顾问"到"助理"，你已经拥有了一个真正帮你干活的 AI。**

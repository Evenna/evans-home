
# 模块二 · 办公实战

## 第 7 课 · 办公三件套：一句话出 Word / Excel / PPT

### 🎯 本课目标
用一句话生成周报（Word）、表格（Excel）、演示文稿（PPT），并从右侧结果区下载。这是职场人用得最多的功能。

### 📖 知识点：说清需求，结果差十倍
诀窍是**把需求说清楚**（万能公式：背景 + 目标 + 具体要求 + 输出格式，第 24 课细讲）。

❌ 差：「帮我写个周报」（它不知道你干了啥，只能瞎编）
✅ 好：「我是运营，本周做了 3 场直播、5 篇推文、参加选题会。生成本周周报，Word，分『本周完成』『下周计划』『问题与风险』三部分，语气正式。」

### ✋ 实操案例

**案例 A · 周报（Word）**
```
我是市场部专员，本周完成：新品发布会筹备、2 篇公众号推文、
对接 3 家媒体。写一份本周工作周报，Word，
分「本周完成」「下周计划」「需要支持」三板块，语气正式。
```

**案例 B · 项目排期表（Excel）**
```
做一份项目排期表，Excel，含列：任务名称、负责人、
开始时间、结束时间、状态。预填 10 行示例数据。
```

**案例 C · 从大纲生成 PPT**
```
按以下大纲做 15 页 PPT，简洁商务风，配色深蓝+白：
1. 封面：产品名+Logo  2. 目录
3-5. 行业痛点（3页）  6-9. 核心功能（4页，每页一个）
10-12. 竞品对比（3页）  13. 商业模式  14. 团队  15. 联系方式
```
它自动排版、配图、统一风格，右侧产出可下载的 **.pptx**。

### 💡 小技巧：分步迭代
做 PPT 建议：**先出框架 → 确认结构 → 生成完整 PPT → 微调风格**。比一次丢一大堆要求好得多。追问示例："第 3 页配一张图""整体字号调大""把竞品对比改成表格"。

### 📝 课后作业
用案例 A 模板，换成你真实的工作，生成一份自己的周报并下载。

## 第 8 课 · 数据分析与可视化：拖一份 Excel 出报告

### 🎯 本课目标
把一份 Excel 丢给它，自动清洗、算汇总、出图表，产出带交互图表的分析报告——**不用会函数、不用会画图**。

### 📖 知识点：全自动五步
你只要把文件拖进对话框，用大白话说想看什么，它全自动完成：**读取 → 清洗 → 计算 → 画图 → 生成报告**。

### ✋ 实操案例：销售数据分析
1. 把 Excel（假设有：日期、产品、区域、销售额）拖进对话框
2. 输入：
```
分析这份销售数据，按月汇总各产品线销售额，
生成柱状图和趋势折线图，找出销售额 Top 5 区域，
输出一份含图表的分析报告（HTML 格式）。
```
3. 不到 1 分钟，右侧出现可预览的 **HTML 报告**，含交互式图表。

**还能让它做的分析：**
- 「找出这份数据里的异常值和下降最快的产品」
- 「按季度对比，用一段话总结趋势」
- 「把结论做成 3 页 PPT，给领导汇报用」

### 💡 小技巧
- 看不懂的列先用 **Ask 模式**问：「这份数据有哪些字段？每列什么意思？」
- 报告不满意直接追："图表换暖色系""加一段执行摘要""按区域再拆一层"，它在原报告上改。
- **数据脏也没关系**：让它先"清洗并说明清洗了什么"，你就知道它动了哪些数据。

### 🚧 边界与人工关口
数据分析结论**可信度依赖数据质量**。涉及给领导/客户的关键结论，务必人工复核口径（比如"销售额"是否含退款、时间窗口对不对）。**AI 缩短处理时间，判断仍归你。**

### 📝 课后作业
找一份真实数据（销售、考勤、账单都行），出一份分析报告，体验"不会 Excel 也能做数据分析"。

## 第 9 课 · 文件识别与批量处理：发票 / 图片 / 文档

### 🎯 本课目标
让它批量重命名、归类、识别文件——那些手动做要半天的机械杂活。以"发票整理登记"为进阶案例。

### 📖 知识点
WorkBuddy 能**读写你授权的本地文件夹**。重复 100 遍的机械操作，一句话交给它。
> ⚠️ 安全提示：它只能操作你**授权**的文件夹。第一次操作某目录时看清提示、确认路径再放行。

### ✋ 实操案例

**案例 A · 批量重命名图片**
```
读取 D:\Photos\2026 下所有图片，按拍摄日期重命名为
20260601_153000.jpg，再按月份归类到子文件夹（2026-06/）。
```
它读每张图的 EXIF，批量改名+分类，给你一份处理日志。

**案例 B · 整理下载文件夹**
```
整理下载文件夹，按类型分到子文件夹：
文档→Docs、图片→Images、安装包→Installers、压缩包→Archives。
```

**案例 C · 发票整理与登记（进阶，L2）**
```
读取「报销发票」文件夹里所有发票图片/PDF，识别每张的：
发票号码、开票日期、金额、税额、销售方名称，
汇总成 Excel 台账，统计总金额，标出金额异常（如超 5000）的行。
```
这一步考验**文件识别 + 表格 + 金额复核**三件事。识别完成后，**金额务必人工抽查几张**——这是财务场景的铁律。

### 💡 小技巧
- 拿不准会不会误删？先用 **Plan 模式**让它列"打算怎么操作"，确认后再执行。
- 重要文件先备份，养成习惯。

### 📝 课后作业
挑电脑里最乱的文件夹（下载夹通常是重灾区），让它整理归类一次。有条件的用真实发票试案例 C。

## 第 10 课 · 会议协同：录音 → 纪要 → 待办 → 周报

### 🎯 本课目标
把"开会"变成一条流水线：**会议录音 → 结构化纪要 → 待办清单 → 汇报材料**，会议结束不再是终点。

### 📖 知识点：会议的价值在会后
大多数人开完会就散了，行动项没人跟。WorkBuddy 能把会议纪要变成"能追踪的待办"。链路：
> 录音/转写 → 纪要（决议 + 讨论 + 遗留问题）→ 待办（谁、做什么、何时）→ 同步到文档/IM → 生成周报

### ✋ 实操案例

**案例 A · 从录音/文字稿出纪要**
```
这是今天产品评审会的录音转写（附件）。整理成会议纪要：
1. 一句话会议结论  2. 关键决议（编号）
3. 讨论要点  4. 遗留问题
5. 待办清单：任务 | 负责人 | 截止时间（表格）
```

**案例 B · 待办转跟进**（配合腾讯文档连接器，见第 12 课）
```
把上面的待办清单写入我腾讯文档「本周待办」，
并在每个负责人名字后加一句一句话的跟进话术草稿。
```

**案例 C · 多次会议汇总成周报**
```
读取我这周三次会议的纪要，提炼成一份汇报周报：
本周关键决策、进展、卡点、下周重点，给领导看，正式简洁。
```

### 🚧 边界
纪要里**不要把"讨论中的推测"写成"已确认的结论"**。让它区分"决议"和"待确认项"，重要决议人工核对原话。

### 📝 课后作业
下次开会录一段音（或用文字稿），跑一遍 A→B，体验"会议结束 5 分钟出纪要和跟进"。

## 第 11 课 · 深度调研：从一个问题到一份带证据的报告

### 🎯 本课目标
让它联网调研一个课题，产出一份**带来源证据、可追溯**的专业报告——而不是一堆看起来对但没出处的"AI 口水"。

### 📖 知识点：调研的关键是"证据可追溯"
好的调研报告 ≠ 长。核心是**每个关键结论都能溯源**。让它输出时带上：
> 结论 → 支撑证据 → 原始来源链接 → 可信度/待确认项

用 **Plan 模式**做调研最稳：它先列调研提纲、信息源计划，你确认方向再让它开搜，避免跑偏浪费积分。

### ✋ 实操案例：市场/竞品调研
```
用 Plan 模式：调研 2026 年国内 AI 编程助手市场。
先列调研提纲和信息源计划让我确认，然后：
1. 主要玩家对比（产品、定价、差异化）——做成表格
2. 技术趋势  3. 市场规模与增长
4. 每个关键数据附来源链接，无法核实的标「待确认」
输出 3000 字 Markdown 报告 + 一张竞品对比表 + 一张来源证据表。
```

**进阶 · 多源交叉验证**：涉及重要数字，让它"用多个来源交叉验证，冲突的地方标注出来"。这就是蓝皮书说的"来源补证与事实核查"。

### 💡 小技巧
- 报告太长抓不住重点？追一句："开头加一段 200 字执行摘要，给忙的人看。"
- 想要不同深度？"基础版给资料摘要，进阶版给证据矩阵。"

### 🚧 边界（重要）
AI 适合**缩短资料处理时间，不适合隐藏来源直接给结论**。投资、法律、医疗类调研，观点和最终判断必须由人承担。让它做"资料 + 证据 + 待确认项"，把"拍板"留给你。

### 📝 课后作业
选一个你工作相关的课题，用 Plan 模式做一份带来源证据表的调研报告。检查：有几个结论是能点开链接溯源的？

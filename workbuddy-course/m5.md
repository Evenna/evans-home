
# 模块五 · 多 Agent 专家团

## 第 19 课 · 专家与专家团：从一个人到一支团队

### 🎯 本课目标
理解"专家"和"专家团"是什么，学会召唤和创建专家——从"AI 同事"升级到"AI 部门"。

### 📖 知识点：四种用法档位（回顾 + 深入）
| 方式 | 本质 | 适合的问题 |
|------|------|------|
| 普通任务 | 通用理解与执行 | 一次性的清楚任务 |
| Skill | 特定工具能力 | 需要稳定执行某个动作 |
| **专家** | **人设 + 方法论 + 工具链** | 明确领域的单点专业问题 |
| **专家团** | **多位专家 + 协作流程** | 需拆解、并行、汇总的复杂项目 |

**专家 = 角色切换机制。** 通过人设、方法论、工具链，让 WorkBuddy 以某领域专家的身份工作。同样分析销售数据：
- 普通 Agent：读数据 → 出图 → 总结。
- 数据分析**专家**：理解业务目标 → 定核心指标 → 查数据质量 → 找异常 → 分析原因 → 给可执行建议。

**专家团 = 协作执行机制。** 一个专家团由多位专家组成，**团长自动拆解任务、分配工作、并行执行、整合交付**。你只需告诉团长背景、需求、预期成果——不用自己挑团员、不用自己拆任务。

### ✋ 实操

**召唤一位专家：**
打开「专家·技能·连接器」→ 选「专家」→ 点「召唤专家」。以"高考我帮你"专家为例，输入任务："帮我查一下 2026 年高考数学真题"，等结果。

**创建一位专家（把你的方法论人格化）：**
点「我的专家」→「创建专家」。比如创建一个"公众号创作专家"，写清它的人设、方法论、常用工具，生成后测试，之后可在"我的专家"里随时召唤。

**召唤一个专家团：**
打开「专家·技能·连接器」→ 选「专家团」→ 点「召唤」。任务开始前先确认四件事：
1. 成员分工是否覆盖完整？　2. 哪些步骤依赖前一步？
3. 什么时候需要人来拍板？　4. 最终由谁整合？

### 💡 怎么选
- 单点专业问题 → 一位**专家**就够。
- 跨多专业、多步骤、能并行的大项目 → 上**专家团**。
- 别为了"看起来高级"给简单任务上专家团——那是杀鸡用牛刀，还费积分。

### 📝 课后作业
创建一位和你工作最相关的专家（把你的一套方法论写进它的人设），召唤它做一个真实任务，对比它和"普通任务"的产出差别。

## 第 20 课 · 多 Agent 系统设计：角色契约 + 共享产物层

### 🎯 本课目标
学会**设计**一条不断档的 AI 生产流水线——这是 L4 的核心技能。不是角色越多越好，而是每个角色都有清晰的输入、输出和边界。

### 📖 知识点一：这个任务值得拆成多 Agent 吗？
满足越多，越适合上专家团：
- 至少两个子任务可以**独立进行**；
- 子任务需要**不同的方法、资料或工具**；
- 输出可以定义清楚的**交接格式**；
- 并行能**显著缩短等待**；
- 有明确的**总负责人和最终验收**；
- 预算允许多轮调用。

> ❌ 反例：只改一封邮件、总结一份 PDF、格式化一个表格——**不需要专家团**，一个普通任务或一位专家就够。

### 📖 知识点二：角色契约（多 Agent 不乱的关键）
每个角色必须写清三件事：**输入、输出、禁止动作**。以"产品宣传片专家团"为例：

| 角色 | 输入 | 输出 | 禁止动作 |
|------|------|------|------|
| 主理人 | 用户任务描述、素材空间 | 任务拆解、状态追踪、成片 | 不跳过子任务验收直接交付 |
| Brief 角色 | 产品官网、介绍文档 | brief.md（定位、价值、目标用户） | 不直接写脚本 |
| 分镜师 | brief.md | 分镜表（时间码、画面、字幕、转场、动效） | 不引入 Brief 未确认的信息 |
| 素材师 | 分镜表 | 产品截图、概念图、界面素材 | 不使用无版权来源素材 |
| 剪辑师 | 素材、分镜表 | 逐帧 MP4 片段 | 不改动分镜结构 |
| 配乐师 | 分镜表、情绪标注 | BGM 候选及推荐理由 | 不只输出一个选项 |

**为什么"禁止动作"这么重要？** 它防止角色越界——分镜师不能自己编 Brief 里没有的卖点，剪辑师不能改分镜结构。**边界清晰，流水线才不会各说各话。**

### 📖 知识点三：共享产物层（单一事实来源）
多个 Agent **不应各自维护一份"产品事实"**，否则会出现"Brief 说 A、分镜师记成 B"的错乱。建立**单一产物路径**，大家读写同一批文件：
```
project/
├── brief.md          # 产品简报（Brief 角色产出，主理人确认）
├── storyboard.md     # 分镜表（分镜师产出，主理人确认）
├── assets/           # 素材（素材师产出）
│   └── screenshots/
├── clips/            # 逐帧片段（剪辑师产出）
└── final.mp4         # 成片（主理人整合）
```
这就是第 3 课"工作区"概念的真正用武之地——**工作区 = 专家团的共享桌面。**

### 📖 知识点四：检查点（人在关键节点拍板）
全自动 ≠ 全程不管。在关键节点设**人工检查点**：
- Brief 出来后 → 你确认"卖点抓对了吗"
- 分镜出来后 → 你确认"节奏、镜头顺序 OK 吗"
- 成片出来前 → 你确认"字幕、BGM、版权没问题吗"

> 主理人的一条铁律：**不跳过子任务验收直接交付。**

### ✋ 实操：设计你自己的专家团（练习）
挑一个你的复杂项目（如"月度经营分析"），照着填这张设计表：
1. **值不值得拆**：对照知识点一的 6 条打勾。
2. **拆几个角色**：每个角色写清 输入 / 输出 / 禁止动作。
3. **共享产物层**：定义大家读写的文件目录结构。
4. **检查点**：标出哪几步需要你拍板。

### 📝 课后作业
用上面的设计表，为你工作中的一个复杂项目设计一个专家团（先在纸上/文档里设计，不用真跑）。重点练"角色契约"和"共享产物层"。

## 第 21 课 · 实战：一句话召唤 AI 视频团队（生成 + 拆解）

### 🎯 本课目标
把前面的理论落地——用两支专家团做短视频：一支**生成**视频，一支**拆解**爆款。体验"从主题到成片全自动"。

### 📖 知识点：两支互补的团队
| 团队 | 负责什么 | 适合 |
|------|------|------|
| **视频生成团队** | 从主题出发：热点采集→选题→脚本→分镜→配音→渲染→字幕→发布 | AI 周报、产品更新、知识科普、行业分析 |
| **爆款拆解团队** | 从视频链接出发：下载→提音频→转文案→分析镜头语言→拆解报告+仿拍建议 | 学爆款结构、复盘竞品、沉淀拍摄手册 |

它们不是替代关系：**生成团队解决"今天怎么做一条出来"，拆解团队解决"为什么别人那条能火"。** 一个负责生产，一个负责学习，组合起来才能持续迭代。

### ✋ 实操 A：召唤视频生成团队
```
召唤视频生成团队，制作一条 46 秒 AI 周报短视频。
```
生成团队的四个核心角色（一条有上下游交接的生产线）：

| 角色 | 定位 | 交付物 |
|------|------|------|
| 凌导 | 主理人/团长 | 拆任务、编排并行/串行、汇总产物、处理检查点 |
| 灵阅 | 信息采集员 | 热点池、来源表、去重后的结构化摘要、选题候选 |
| 灵枢 | 内容策划师 | 选题判断、脚本、分镜、旁白、转场、素材清单、BGM/字幕节奏 |
| 灵映 | 视频制作师 | HTML 视频工程、配音、字幕对齐、转场动画、渲染成片 |

**生产流程四步（每步都有检查点）：**
1. **采集**：灵阅抓 RSS/新闻/社媒/AI 热点，去重输出结构化摘要（含标题、来源、时间、原始链接、为什么值得关注）。热度只帮排序，不替代事实核验。
2. **策划**：灵枢把主题变成镜头（选题评估、脚本、分镜、旁白、节奏、BGM、字幕停顿）。
   → 🚩 **第一次人工检查**：开头 3 秒有钩子吗？46 秒信息塞太多没？旁白准不准？画面撑得住观点吗？不过关就别进配音渲染。
3. **制作**：灵映把脚本转 HTML，调用渲染引擎（HyperFrames）出 MP4，自动完成 TTS 配音、字幕对齐、转场、素材拼接。
   → 🚩 **成片验收**：旁白与字幕一致？镜头时长匹配？文字没遮主体？BGM 可用？素材有版权风险没？
4. **发布**：可自动生成标题/标签/封面并发到抖音/视频号/B站。
   → 🚩 **铁律**：**发布默认不要全自动**，账号、素材、标题、合规都人工确认后再发。

### ✋ 实操 B：召唤爆款拆解团队
```
拆解这条视频：[视频链接]。下载视频、转写文案、分析镜头语言，
给我一份拆解报告 + 仿拍建议。
```
拆解团队角色：**阿爆**（团长/总控）、**小凯**（音频转录：ffmpeg + ASR 把口播转文案）、**小淼**（视频理解：分析景别、运镜、转场、剪辑节奏、色调、镜头时长）。
> 视频下载用**三层降级策略**（官方 API → Playwright → yt-dlp），有一层成功就继续。

### 🚧 边界（内容创作者必读）
- 拆解的目的是**学结构和方法，不是搬运原视频**。
- 视频下载/分析要**遵守平台条款、版权授权、合理使用**。
- 发布前过一遍**事实、版权、品牌**三道审核。

### 💡 闭环打法
用拆解团队分析 5 条同赛道爆款 → 沉淀成"选题评分表 + 分镜模板" → 喂给生成团队 → 生成团队按学到的规律产出 → 数据复盘 → 再优化模板。这就是蓝皮书说的"增长闭环"。

### 📝 课后作业
先用拆解团队拆一条你赛道的爆款，产出一份拆解报告；再用生成团队按学到的规律做一条 30-46 秒短视频。全程注意在每个 🚩 检查点亲自拍板。


# 模块六 · 提示词工程 · 岗位行业落地 · 毕业项目

## 第 22 课 · 提示词工程深挖：把话说到 AI 心里去

### 🎯 本课目标
系统掌握"怎么跟 WorkBuddy 提需求"——同样一个任务，会提需求的人拿到的是成品，不会提的人拿到的是"再改改"。

### 📖 知识点一：万能任务公式
> **背景 + 目标 + 输入 + 输出要求 + 边界/禁止 + 验收标准**

| 要素 | 作用 | 例子 |
|------|------|------|
| 背景 | 让它理解场景 | "我是做跨境电商的，这是给欧洲客户的邮件" |
| 目标 | 一句话说清要什么 | "把这封中文邮件改成正式英文" |
| 输入 | 给它原料 | "原文在这个文档 / 我贴在下面" |
| 输出要求 | 格式、长度、风格 | "300 字内，商务正式，带主题行" |
| 边界/禁止 | 划红线 | "不要编造未确认的发货日期" |
| 验收标准 | 什么算做对 | "对方能直接回复下单即合格" |

### 📖 知识点二：从"模糊"到"精准"的进化
| ❌ 模糊 | ✅ 精准 |
|------|------|
| "帮我写个方案" | "写一份新品上市方案，面向 25-35 岁女性，含定价/渠道/首月节奏，输出到腾讯文档，1500 字内" |
| "分析下数据" | "分析这份销售表：找出环比下滑最大的 3 个品类，给出可能原因和 2 条建议，做成表格" |
| "做个视频" | "做一条 30 秒产品介绍短视频，开头 3 秒要有钩子，突出'防水'卖点，竖屏，配字幕" |

### 📖 知识点三：五个高阶技巧
1. **给例子（few-shot）**："照这个风格写：[贴一段范例]"——比形容词管用一百倍。
2. **让它先规划（用 Plan 模式）**：复杂任务先让它出方案，你确认再执行，省得跑偏。
3. **分步下达**：大任务拆成"先做 A，我看完再做 B"，比一口气全丢过去更可控。
4. **明确"不要什么"**：负向约束（不要编数据、不要用某风格、不要超过 X 字）往往比正向更有效。
5. **让它自检**："完成后检查：字数够吗？有没有编造的事实？格式对吗？"——把验收标准也交给它。

### 📖 知识点四：提需求的三个反模式
- **一次性塞太多**：一句话里塞十个要求，它会漏。→ 拆开。
- **只给形容词不给标准**："写得高级点"——它不知道你的"高级"。→ 给例子或量化。
- **不给背景**：它不知道你是谁、给谁看，只能猜。→ 补背景。

### 📝 课后作业
挑你上周提过的一个"结果不满意"的需求，用万能公式重写一遍，对比两次产出的差别。

## 第 23 课 · 岗位落地：把 AI 装进你的具体工作

### 🎯 本课目标
不再泛泛而谈，而是落到**你的岗位**——学会用"成熟度四级"给自己规划落地路线，用"岗位场景表"找到第一个下手点。

### 📖 知识点一：岗位能力成熟度四级
别想着一步到位，按台阶走：

| 级别 | 能力 | 典型产物 | 进阶信号 |
|------|------|------|------|
| **L1 单次辅助** | 一次性帮忙 | 会议纪要、文章摘要、翻译 | 同类任务连续成功 3 次 |
| **L2 固定模板** | 可复用的稳定模板 | 周报、复盘、标准邮件 | 输入字段、验收规则稳定下来 |
| **L3 工作流** | Skill + 资料库 + 连接器串起来 | 端到端流程（如自动日报系统） | 有负责人、有日志、能处理异常 |
| **L4 团队能力** | 专家团 + 自动化 | 跨职能项目（如视频生产线） | 有权限、成本、资产治理 |

> 🎯 **给自己定位**：你现在在哪一级？下一步该积累什么才能进阶？

### 📖 知识点二：六大岗位场景速查表
找到你的岗位，从"风险低、频率高"的场景先下手：

| 岗位 | 高频场景 | 输入 | 交付物 | 风险点（人工关口） |
|------|------|------|------|------|
| 产品经理 | 需求整理、竞品分析、PRD 初稿 | 用户反馈、竞品资料 | 需求列表、竞品表、PRD 草稿 | 需求优先级需人拍板 |
| 运营/市场 | 内容排期、文案、数据周报 | 选题、后台数据 | 排期表、文案、周报 | 对外发布前审核 |
| 销售/售前 | 客户资料整理、方案、跟进纪要 | 客户信息、产品资料 | 客户画像、方案初稿 | 报价/承诺需人确认 |
| HR/行政 | JD 撰写、简历初筛、制度整理 | 岗位需求、简历 | JD、初筛结果、制度文档 | 录用决策不能全交 AI |
| 财务/法务 | 数据整理、合同要点、报表初稿 | 流水、合同 | 汇总表、要点清单 | 合规/金额必须人工复核 |
| 研发/IT | 文档、代码解释、日志分析 | 代码、日志、需求 | 文档、排查建议 | 上线/删改需人工执行 |

### 📖 知识点三：部门推广模板卡
想在团队推广？照这张卡把一个流程说清楚，谁接手都能复用：

| 字段 | 内容 |
|------|------|
| 原流程 | 原来这件事怎么做、几个人、多久 |
| 输入 | 需要哪些资料/文件/权限 |
| 输出 | 产出什么、什么格式 |
| 验收标准 | 什么算合格 |
| 人工关口 | 哪几步必须人来拍板 |
| 关键指标 | 用什么衡量效果（省时/质量/成本） |
| 负责人 | 谁维护、谁背锅 |

### 📝 课后作业
用"成熟度四级"给自己定位，再从你岗位的场景表里挑一个"风险低、频率高"的场景，写一张部门推广模板卡。

## 第 24 课 · 毕业项目：从零搭一条属于你的 AI 生产线

### 🎯 本课目标
把整门课学的东西串起来，**独立完成一个端到端项目**。这是你的结业作品，也是你未来向团队展示的样板。

### 📖 毕业项目要求
选一个**你工作中真实、重复、有价值**的流程，用 WorkBuddy 把它做成一条能复用的生产线。必须覆盖：

- ✅ **至少 1 个连接器**（邮箱/文档/飞书/Notion 等）
- ✅ **至少 1 个 Skill**（官方或自己搭的）
- ✅ **一套稳定的提示词/模板**（用万能公式写）
- ✅ **可复现**（换个输入也能跑，不是一次性）
- ✅ **明确的人工关口**（标出哪一步你要拍板）
- ✅ **进阶项（可选）**：定时自动化 / 多 Agent 专家团 / 执行日志

### ✋ 三个参考选题（按难度）

**🥉 入门级 · 每周竞品动态简报**
连接器（公众号监控/GitHub 热点）+ 资讯 Skill + 固定周报模板 → 每周五自动生成竞品动态，发到飞书。对应 L2→L3。

**🥈 进阶级 · 客户资料到方案的流水线**
连接器（腾讯文档）+ 客户画像 Skill + Plan 模式方案模板 → 输入客户信息，产出画像 + 方案初稿，报价处留人工关口。对应 L3。

**🥇 挑战级 · 内容生产 + 拆解双团队**
视频生成团队 + 爆款拆解团队 + 共享产物层 + 发布人工关口 → 拆解 5 条爆款沉淀模板，喂给生成团队产出短视频，形成增长闭环。对应 L4。

### 📋 交付清单（做完自查）
1. 一段话说明：这条生产线解决什么问题、原来怎么做、现在怎么做。
2. 流程图或步骤说明：每一步谁（哪个 Skill/专家）做、输入输出是什么。
3. 用到的提示词/模板（可复制）。
4. 人工关口清单：哪几步你拍板、为什么。
5. 一次真实运行的结果截图/产物。
6. 复盘：省了多少时间、还有什么坑、下一步怎么优化。

### 🎓 结业寄语
> 学完这门课，你手里有的不是"会用一个 AI 工具"，而是**一套把重复工作变成可复用生产线的方法论**。工具会变，但"拆解任务 → 定义角色 → 划清边界 → 留好人工关口 → 持续复盘"这套思路不会过时。去把你工作里最烦、最重复的那件事，做成第一条生产线吧。

### 📝 结业作业
提交你的毕业项目（按上面 6 项交付清单）。这就是你的 WorkBuddy 结业作品。

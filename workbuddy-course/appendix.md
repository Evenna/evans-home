## 附录 B · 避坑手册（12 条真实教训）

1. **用连接器前先在设置里开授权**——没开就让它连邮箱/文档，一定失败。
2. **自动任务要电脑开机**——它在你本机跑，关机就断。
3. **发布类动作别全自动**——发抖音/公众号默认留人工确认，账号/合规/版权先过一遍。
4. **财务、法务、录用决策不能全交 AI**——涉及金额、合规、人的决定，必须人工复核。
5. **别一句话塞十个要求**——它会漏，拆开分步下达。
6. **重要数字让它标来源**——"这个结论基于哪份数据？"防止它编。
7. **明确说"不要什么"**——负向约束比正向更有效（不要编、不要超字数、不要用某风格）。
8. **复杂任务用 Plan 模式**——先出方案你确认，别让它闷头跑偏。
9. **热度 ≠ 事实**——资讯类结果推送前过一遍事实核查。
10. **专家团不是越多越好**——简单任务上专家团是浪费积分，先判断"值不值得拆"。
11. **多 Agent 要有共享产物层**——否则各记各的，Brief 和分镜对不上。
12. **积分会花**——图片/视频比文字费积分，跑大任务前看下余额，先手动小跑再放大。

## 附录 D · 术语表（小白友好）

| 术语 | 一句话解释 |
|------|------|
| Agent（智能体） | 能自己拆解并完成任务、直接出成品的 AI，不只是聊天 |
| Craft 模式 | 立即执行，90% 日常用它 |
| Plan 模式 | 先出方案给你确认，再执行，适合复杂任务 |
| Ask 模式 | 只聊天、不碰你的文件 |
| Skill（技能） | 一个能稳定执行某动作的工具能力（如抓 GitHub 热点） |
| 连接器 | 把 WorkBuddy 连到你的邮箱/文档/飞书等，让它能读写 |
| 专家 | 带人设+方法论+工具链的 AI，某领域的单点高手 |
| 专家团 | 多位专家 + 团长协作，处理需拆解的复杂项目 |
| 团长/主理人 | 专家团里负责拆任务、分配、整合交付的角色 |
| 角色契约 | 每个角色的 输入/输出/禁止动作，防止越界 |
| 共享产物层 | 多个 Agent 读写同一批文件的目录，保证"单一事实" |
| 检查点/人工关口 | 关键步骤停下来等你拍板的地方 |
| 工作区 | 一个任务相关文件的集合，也是专家团的共享桌面 |
| 成熟度 L1-L4 | 从"单次帮忙"到"团队生产线"的四级能力台阶 |
| HyperFrames | 用 HTML 渲染视频的开源引擎（HeyGen 开源） |
| 积分 | WorkBuddy 的用量货币，任务越重耗得越多 |

## 附录 E · 学习路线图与进阶建议

**按周学习节奏（建议）**
| 周 | 学什么 | 目标产物 |
|------|------|------|
| 第 1 周 | 模块一（1-6 课）| 装好、跑通第一个任务、熟悉三模式 |
| 第 2 周 | 模块二（7-11 课）| 用它完成一次真实办公任务（文档/PPT/表格/数据） |
| 第 3 周 | 模块三（12-15 课）| 接一个连接器 + 装一个 Skill，跑通一条小流程 |
| 第 4 周 | 模块四（16-18 课）| 搭一个每日自动任务 + 加日志告警 |
| 第 5 周 | 模块五（19-21 课）| 召唤一次专家团，跑一条视频生产/拆解 |
| 第 6 周 | 模块六（22-24 课）| 完成毕业项目 |

**三条进阶心法**
1. **先解决自己最烦的事**——从你每天/每周重复做的一件事下手，最有动力也最见效。
2. **每个能跑通的流程都存成模板**——积累模板库，就是积累你的"AI 生产力资产"。
3. **边界感比效率更重要**——知道"哪些能全交 AI、哪些必须自己拍板"，才能长期放心地用。

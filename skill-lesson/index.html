口播分镜脚本：Skill 是什么，它在 AI Agent 里是什么

录口播，剪辑时上方叠黑板，关键词逐个蹦。黑板共 4 块，翻页少。约 5 分钟。
【口播】= 你念的；【板书↑】= 此刻蹦出的黑板词。

钩子（0:00 – 0:12）

【口播】

同样一个 AI，为什么有人用得又快又准，你却得反复改？

差的不是 AI，是有人给它加了一样东西——Skill。

今天三分钟，把它讲透。

【板书↑】

Skill = ?

黑板 ①：Skill 在 AI Agent 里是哪一环（0:12 – 1:35）

【口播】

现在能帮你干活的 AI，叫 Agent。它干活不靠一样东西，靠四样配合。

第一样，大模型。就是那个聪明的脑子——会说话、有常识、会推理。但它很通用，不认识你，也不懂你这行。

【板书↑】

大模型 —— 聪明的脑子

【口播】

第二样，记忆。让它记得住你——你是谁、你的偏好、上次聊到哪。

【板书↑】

记忆 —— 记住你

【口播】

第三样，工具。让它有手有脚——能上网、能跑代码、能改文件。有了工具，它才从"会聊天"变成"能动手"。

【板书↑】

工具 —— 手和脚

【口播】

第四样，就是 Skill。前三样是硬件，Skill 是打法。同样的脑子、记忆、工具，配上一套好打法，干出来的活就不一样。

它不比谁高级，它是这四样里专门管"某类活该怎么干"的那一环。

【板书↑】

Skill —— 打法（怎么干）

【口播】

一句话记住：脑子、记忆、工具解决"能不能干"，Skill 解决"干得好不好"。

【板书↑】

四件套：脑子 · 记忆 · 工具 · Skill

黑板 ②：最容易混的两组（1:35 – 2:55）

【口播】

Skill 有两个特别容易被搞混的东西，我一次讲清。

第一组，Skill 和记忆。

记忆存的是"名词"——关于你的事实。Skill 存的是"动词"——做事的流程。

"这个用户是清华的"，是事实，进记忆。"写简历要先核实再拔高"，是流程，进 Skill。一个让 AI 认识你，一个让 AI 会干活。

【板书↑】

记忆 = 记住「是什么」→ 名词

Skill = 会干「怎么做」→ 动词

【口播】

第二组更容易混——Skill 和 system prompt，也就是"系统提示词"。

很多人觉得这俩不是一回事吗，都是"给 AI 定规矩"。不一样，差在两点。

一，system prompt 是总规矩，永远生效。比如"你是一个严谨的助手，说话简洁"——不管你问什么，它一直在后台管着。

Skill 是专项打法，用到才调出来。你不写小红书，那条写小红书的 Skill 就不出现，省地方也不干扰。

【板书↑】

system prompt = 总规矩 · 一直在

Skill = 专项打法 · 用到才调

【口播】

二，system prompt 只有一份，什么都往里塞会越塞越乱。

Skill 可以有几十上百个，一个技能管一类活，各归各的。

所以简单说：system prompt 是"你是谁、总的怎么说话"；Skill 是"遇到这类具体活，一步步怎么做"。 一个是底色，一个是招式。

【板书↑】

底色 = system prompt

招式 = Skill（可以很多个）

黑板 ③：一个 Skill 拆开长什么样（2:55 – 4:05）

【口播】

那 Skill 本身长什么样？不是什么程序，就是一个文件夹。拆开给你看。

里面唯一必须有的，是一个文件，叫 SKILL.md，它是这个技能的大脑。这个文件分两半。

【板书↑】

一个 Skill = 一个文件夹

核心：SKILL.md

【口播】

上半是"帽子"。最关键就一行，写"什么时候该用这个技能"。先记住这行，等会儿还要说它。

【板书↑】

SKILL.md · 帽子：啥时候用它 ★

【口播】

下半是"正文"，大白话写的操作手册：这活儿一步步怎么做、有哪些坑、做完怎么检查。

【板书↑】

SKILL.md · 正文：怎么做 + 坑 + 检查

【口播】

一个 SKILL.md 就能跑。活儿复杂了，文件夹里还能带三样配套：references 放参考资料，scripts 放能直接跑的脚本，templates 放套着填的模板。

记住主次：核心永远是 SKILL.md，那三样是按需才带的弹药。

【板书↑】

可选弹药：references · scripts · templates

黑板 ④：怎么算好 Skill（4:05 – 4:50）

【口播】

最后，怎么算一个好 Skill？三条。

一，帽子写准。还记得刚才那行吗——AI 就是靠它决定"要不要用这个技能"。写含糊了，它根本想不起来用，手册再好也白搭。

【板书↑】

① 帽子写准 → AI 才想得起来用

【口播】

二，步骤能照做。"先做好准备"是废话；"跑这条命令、看到这个就对了"才能照做。

【板书↑】

② 能照做 > 正确的废话

【口播】

三，写坑。只写正确步骤是新手；告诉你"这儿最容易错"的，才是老手。你踩过的坑，最值钱。

【板书↑】

③ 写了坑 = 老手

收尾（4:50 – 5:05）

【口播】

说到底，Skill 不玄乎：把你自己会干的一类活，用人话写成一份能交给 AI 的说明书。

你会写便签，就会写 Skill。下期咱们动手写一个。

【板书↑】

Skill = 把你会干的一类活，写给 AI

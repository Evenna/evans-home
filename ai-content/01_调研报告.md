## 2.2 爆款选题方向(18个 + 为什么能火)

**工具清单类(收藏神器)**

2. 「一个网站顶 10 个软件」— 信息增量大,转发高
3. 「2026 必备 AI 工具全景图」— 一张图=收藏爆款

**Agent 实操类(核心)**

5. 「我用 Coze 做了个自动回复,一晚省 2 小时」— 真实成果可信
6. 「一个 Agent 帮我自动做小红书」— AI+副业双热点

**提效/职场类**

**变现类(转化)**

**认知/趋势类(拉互动)**

## 2.3 小红书标题/封面/正文套路

**标题公式**(小红书标题=封面大字延伸,决定点击):
- 数字+利益:「5 个 AI 神器,效率翻 10 倍」
- 反差惊叹:「离谱!这个 Agent 一晚帮我干完一周的活」
- 身份+痛点:「设计师快看!AI 自动改稿救命了」
- 私藏/独家:「私藏!压箱底的 AI Agent 清单」
- 保姆级+收藏:「保姆级!0 基础搭 Agent(建议收藏)」
- emoji 点缀:标题穿插 🔥✅💡 提升点击

**封面(小红书成败 70%)**:
- **大字报**:封面必须有超大标题字(3–8 字核心利益),手机端一眼可读
- **对比图**:左"痛苦手动" vs 右"AI 一键搞定"
- **成果展示**:直接放最惊艳的 AI 生成结果/自动化截图
- **清单感**:数字+竖排列表暗示"干货满满"
- **张一文优势**:美院背景做**高级感封面**(统一配色/字体/留白)= 对同行降维打击,天然点击率高

**正文结构(图文笔记标准骨架)**:
```
钩子首句(痛点/结果前置,前 2 行决定是否展开)
→ 结论先行(这篇给你什么)
→ 分点正文(1️⃣2️⃣3️⃣,每点配图/截图)
→ 关键 Prompt/步骤单独成块(方便照抄)
→ 避坑提醒(体现专业)
→ 总结清单(可截图收藏)
→ 结尾引导(见 2.4)
→ 20 个精准话题标签(#AI工具 #AIAgent #AI教程 #Coze 等,SEO 命门)
```

## 2.4 涨粉 + 转化打法

**软性转化路径**(小红书严禁硬广/明显引流,否则限流):
```
干货笔记(工具/Agent教程)→ 评论区高频问题埋钩子 →
主页简介留"AI Agent 干货|资料见置顶" → 私信关键词自动发资料 →
引导加微信/进群(用"薯队长不查"的合规话术,如"主页有联系方式") →
私域社群养熟 → 低价体验课 → 正价 Agent 课
```
- **评论区运营**:置顶自己的补充(领资料引导),主动回复前 20 条评论养热度
- **私信**:开通"薯条自动回复",关键词(如"模板""资料")自动发引流话术
- **合规红线**:正文/评论不直接出现微信号、二维码、"加V";用"主页""私信我""扣1"
- **专栏/合集**:把系列笔记归到合集(如"Agent 从0到1"),提升追更和权重

## 2.6 小红书算法/流量机制要点

- **搜索权重极高**:小红书是"生活搜索引擎",标题+正文+标签的关键词决定搜索露出。→ **教程/工具类严重吃搜索长尾**,常青流量比追热点更稳。
- **收藏 > 点赞**:干货类靠收藏起量,收藏是"有用"强信号。
- **完读率 + 互动**:图文看完读,视频看完播;评论/收藏/转发拉推荐。
- **标签**:每篇 10–20 个精准话题标签,大小词搭配(#AIAgent 大词 + #Coze教程 小词)。
- **发布时间**:早 7–9、午 12–13、晚 20–22 点(用户刷小红书高峰)。
- **避坑**:①禁硬广/导流词限流 ②禁二维码/微信号 ③封面别用违规词 ④别蹭无关热点标签(判定作弊)⑤新号别频繁改赛道(乱标签)。
- **账号垂直度**:持续发同一赛道,养精准标签,系统才会推给对的人。

## 2.7 红利点与空白机会

**红利**:①Agent/扣子实操教程供不应求 ②AI+设计/创意工作流(张一文主场)几乎无人系统做 ③Agent Skill/Prompt 模板天然是最好 lead magnet ④"0 代码"降门槛叙事正热。
**空白**:①"设计师/创意人的 Agent 实操"= 张一文独占位 ②"真人+真实成果+审美"信任型账号稀缺(对冲割韭菜印象)③垂直行业 Agent 方案(自媒体 Agent、设计 Agent)无人深做。

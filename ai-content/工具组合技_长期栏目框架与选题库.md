# 「AI 工具组合技」长期栏目 —— 框架 + 30+ 选题库

> 定位升级：从"讲单个技巧"升级为**"两个（或多个）工具串起来，干成一件具体的事"**。
> 一句话栏目心法：**别人教你用一个工具，我教你把两个工具接成一条流水线，10 分钟出成果。**
> 为什么这个方向更能火、更能转化：
> - **可复现** = 观众照着做立刻出结果 → 强收藏、强转发（"存下来周末试"）
> - **有落差** = "原来这俩能这么连" → 打破认知 → 评论区炸
> - **天然指向课程** = 单条教一个组合，课程教"一整套工作流体系" → 转化逻辑不生硬

## 一、栏目的"万能组合公式"（每条都套这个）

```
【钩子】：一句痛点 or 反差
   → "做一条口播视频要 3 小时？我用 A+B 把它压到 20 分钟"
【场景】：这个组合解决什么真实场景（越具体越好）
   → "把一篇公众号文章，变成一条带字幕的竖屏口播"
【流水线】：A 工具做什么 → 交给 B 工具做什么（画出"接力棒"在哪）
   → "① A 生成分镜脚本 → ② 复制进 B → ③ B 自动配音+字幕+卡点"
【关键动作】：只讲 1-2 个"不说就不知道"的关键设置（这是干货密度）
   → "B 里这个开关要打开，否则字幕不跟画面"
【成果对比】：Before / After（时间、质量、成本任选一个维度）
【一句心法】：把这个组合抽象成一个可迁移的思维
   → "AI 工作流的本质：让每个工具只干它最擅长的一段"
【轻转化】：钩子指向课程 / 合集 / 社群
   → "完整的 12 条工作流我整理成了一份图谱，评论区 1 你"
```

**产出速度目标**：确认工具后，每条成稿 10-15 分钟。

## 二、组合技的"选题矩阵"（横轴工具 × 纵轴场景 = 无限选题）

这是让这个栏目**长期不缺选题**的核心方法论：建一张矩阵，横轴放你会的工具，纵轴放高频工作场景，每个交叉点就是一条选题。

**纵轴：6 大高频场景（受众都有痛点）**
1. 出内容（写文案 / 做口播视频 / 做图文）
2. 做设计（封面 / 海报 / PPT / 长图）
3. 搞素材（找图 / 生图 / 生视频 / 配音）
4. 做整理（会议纪要 / 资料汇总 / 知识库）
5. 做自动化（定时任务 / 批量处理 / 数据抓取）
6. 搞转化（做落地页 / 做表单 / 做客服话术）

**横轴：把你真在用的工具填进来**（等你确认后我补全）
- 对话/Agent 类：〔ChatGPT / Claude / 元宝 / …〕
- 视频类：〔ChatCut / 剪映 / 即梦 / 小云雀 …〕
- 设计类：Canva / 〔Figma / 稿定 …〕
- 编排/自动化类：〔Coze / n8n / Dify / 飞书多维表 …〕
- 生产力：〔Notion / 飞书文档 …〕

> 矩阵一填满，光"AI × Canva"这一列就能出 6 条，×N 个工具 = 几十上百条选题不重样。

## 三、30 条工具组合选题库（现成可拍，按主题组）

> 说明：以下选题结构、钩子、转化点都写死了，可直接用；具体工具操作步骤等你确认工具后填。
> 标 ⭐ 的是"最容易爆 + 最贴合你美院设计师人设"的优先项。

### A 组：出内容流水线（做视频/图文最刚需）
1. ⭐ **一篇文章 → 一条竖屏口播视频**（对话工具写脚本 + ChatCut 自动成片）——痛点最痛、复现率最高
2. **一个选题 → 5 条不同开头的短视频脚本**（Agent 批量生成 + 人工挑）
3. **长视频 → 自动切 10 条精彩片段**（AI 识别高光 + 剪辑工具导出）
4. ⭐ **口播稿 → 带字幕带卡点的成片**（重点讲"字幕跟画面"这个坑）
5. **公众号文 → 小红书图文九宫格**（AI 拆结构 + Canva 套版）

### B 组：设计流水线（你的美院强项，差异化最猛）⭐⭐
6. ⭐⭐ **一句话 → 一套风格统一的封面模板**（AI 定风格 + Canva 出模板）——直接秀审美
7. ⭐ **文章要点 → 信息长图**（AI 提炼结构 + Canva 排版）
8. **产品卖点 → 电商详情页海报**（AI 写卖点 + Canva 出图）
9. **PPT 大纲 → 成套幻灯片**（AI 搭框架 + 设计工具美化）
10. ⭐ **手绘草图 → 成品海报**（拍照上传 + AI 转绘 + Canva 精修）——最"美院"的一条

### C 组：素材流水线
11. **文字描述 → 一组风格一致的配图**（生图工具 + 批量下载）
12. **一张图 → 一段会动的视频**（图生视频 + 剪辑拼接）
13. ⭐ **没有素材？→ AI 生成整套 B-roll 空镜**（解决"口播没画面"的世界难题）
14. **一段录音 → 干净的配音 + 字幕**（转写 + 降噪 + 上字幕）

### D 组：效率/整理流水线（白领受众广）
15. ⭐ **一场会议录音 → 结构化纪要 + 待办**（转写 + Agent 提炼）
16. **一堆网页/PDF → 一份对比表格**（抓取/上传 + AI 汇总）
17. **收藏夹吃灰 → 自动生成知识卡片**
18. **一个主题 → 一份带引用的调研简报**（联网搜索 Agent + 整理）

### E 组：自动化流水线（进阶，最能体现"Agent"含金量）
19. ⭐ **每天早上自动生成一条选题 + 脚本**（定时 Agent，直接对标你自己的号）
20. **新邮件/表单 → 自动分类 + 自动回复草稿**
21. **RSS/公众号更新 → 自动摘要推送到群**
22. ⭐ **表格里一列关键词 → 批量生成一列文案/图**（批量流，最省时间）
23. **网店评论 → 自动情感分析 + 回复模板**

### F 组：转化/变现流水线（服务你自己的课程）
24. **一个课程卖点 → 一张高转化落地页**（AI 写文案 + 建站工具）
25. **常见问题 → 一套客服话术库 + 自动回复**
26. ⭐ **一份免费资料 → 一个"加群领取"的钩子闭环**（这条本身就是在教怎么做转化）

### G 组：认知/避坑（穿插发，降转化密度、涨信任）
27. **"AI 工作流"到底是什么？为什么它比单个工具值钱 10 倍**（栏目定调之作）
28. ⭐ **我踩过的 3 个"工具组合"坑**（真诚感拉满，⚠️ 需你补真实经历）
29. **为什么"设计师 + AI"是被严重低估的组合**（立你的差异化人设）
30. **不要迷信 all-in-one 工具：好工作流都是"专业工具接力"**

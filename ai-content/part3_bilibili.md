## 3.2 爆款选题方向(18个 + 为什么能火)

3. 「手把手用 Coze 搭能干活的 Agent」— 实操录屏,收藏神器

6. 「Claude Code vs Cursor 深度实测」— vibe coding 红利

**成果展示类**

## 3.3 B站标题/封面/脚本套路

**标题公式**:数字+承诺「30分钟学会搭AI Agent(2026最新)」;保姆级+收藏「【保姆级】0基础搭Agent,一个视频讲透」;对比选择「Coze/Dify/n8n到底选哪个?」;反差惊叹「离谱!这个Agent一晚干完我一周的活」;【】包裹关键词。

**封面三要素**:①大标题字(4–8字利益)②产品/成果画面(Coze界面/自动化结果)③高对比配色+可选人脸表情。张一文用美院审美做统一视觉封面矩阵=频道页高级+高点击。

**脚本结构(中长视频)**:
```
0–15s 黄金钩子:直接抛结果/冲突,不自我介绍
       "先看效果:这个Agent 10分钟爬完整个网站——不写一行代码"
15–60s 承诺+路线图:看完你能做到X,本视频分3步
主体   每30–60s一个信息小高潮(open loop);
       用章节分段结构化;长教程"先给成品→再拆步骤"倒叙;
       关键处"这步很多人会卡在…"制造留存悬念
结尾   强CTA三连+引导关注追更系列+推荐下一个视频
```

## 3.4 涨粉 + 转化打法

```
系统教程(建专业权威)→ 简介挂"资料/模板领取"+社群 →
置顶评论再放领取链接 → 动态发预告/答疑 → 粉丝群沉淀 →

```
- 简介可放外链(比抖音宽松),放 lead magnet + 社群入口

- 开充电计划;B站长视频切片发抖音/小红书引流反哺

## 3.6 B站算法/流量机制要点

- **完播率+watch time 是核心**:极度看"看了多久",系统长内容有优势,但前15秒必须留人。
- **三连(点赞/投币/收藏)= 最强正反馈**,投币是B站独有高价值信号。
- **完播>互动>转发**:小流量池测完播,达标进大池。
- **分区/tag**:选对分区(科技·计算机技术),打精准 tag。
- **首发24–48h 定生死**,发布对齐晚间/周末。
- **SEO**:标题/简介前部放关键词,被站内+百度收录,教程吃搜索长尾。
- **避坑**:标题党降权;禁站外导流过度;需原创;避免大段废话掉完播。

## 3.7 红利点与空白机会

**红利**:①Agent/vibe coding 系统教程供不应求 ②新模型实测蹭热点 ③超长旗舰课三收 ④Agent Skill 内容空白。
**空白**:①中文系统有深度的 Agent 实操课稀缺 ②"设计师视角 Agent"= 张一文独占 ③"原理讲透+实操落地"结合无人做全 ④Agent 陪跑社群空间大。

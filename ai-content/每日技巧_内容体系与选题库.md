# 🚀 「每日 Agent 小技巧」内容体系 · 张一文

> 定位:用**每天一个 Agent 小技巧**做高频、易学、易传播的内容,把泛流量沉淀为 AI Agent 课程付费用户。
> 核心逻辑:**小技巧 = 钩子和信任**,**课程 = 系统和交付**。每条内容只教"一个能立刻用上的小点",让人爽到、学到、想学更多 → 报课。

---

## 一、为什么「每日小技巧」是最优转化引擎

| 优势 | 说明 |
|---|---|
| **高频养号** | 日更/隔日更喂算法标签,养出稳定"Agent教学"人设 |
| **低门槛易传播** | 一条=一个小点,3秒看懂、随手收藏转发,完播率高 |
| **天然种草课程** | 每个技巧都是课程某一章的"预告片",学会一个→想要体系 |
| **积累即资产** | 30天=30个技巧库,可合集/可复用/可打包成 lead magnet |
| **信任前置** | 持续给真干货=证明"这人是真会且愿意教",转化时零推销感 |

**一句话心法**:*免费内容负责让人"信你、爱你"，课程负责让人"跟你系统学"。每条小技巧都在悄悄回答一个问题——「这人值不值得付费跟学」。*

## 二、内容三层结构(每条都要想清楚"这条服务转化的哪一环")

```
第1层 · 科普型(20%) —— 建立认知,让人"知道Agent能干嘛、为什么值得学"
        例:"Agent和普通AI到底差在哪""什么是记忆/工具调用/工作流"
        作用:破圈拉新、埋"你需要系统学"心智

第2层 · 技巧型(65%) —— 每日主力,给一个"立刻能抄能用"的小点
        例:"一句话让Agent永远记住你的习惯""这样写指令,Agent不再答非所问"
        作用:拉收藏关注、证明实力、养追更

第3层 · 转化型(15%) —— 成果/案例/学员/趋势,把信任变行动
        例:"我用3个Agent替掉一个团队""学员用这招接单赚了X""不系统学会走的3个弯路"
        作用:软性引导→领资料→进私域→报课
```

> 配比记住:**2:6.5:1.5**。别天天转化(掉粉),也别只科普(不转化)。技巧型是地基。

## 三、每日技巧「万能内容公式」(照着套,10分钟出一条)

**黄金结构(图文/短视频通用):**
```
① 钩子(前3秒/前2行)——痛点或反差
   "你的Agent总答非所问?问题出在这一句话。"
② 一个小技巧(只讲1个点!)——具体、可抄
   给出确切操作/可复制的指令模板
③ 前后对比——展示效果差异(有图更好)
   "改之前 vs 改之后"
④ 一句心法——升华成可记忆的金句
   "指令里加一句'不确定就问我',幻觉少一半。"
⑤ 转化钩子(轻)——领资料/关注/追更
   "这是我《Agent实操课》里第X个技巧,想系统学的扣1"
```

**铁律:**
- **一条只教一个点**(贪多=没人学会=不收藏)
- **必须能立刻抄**(给确切指令/步骤,不空谈)
- **有"前后对比"**(可视化=可信=可传播)
- **每条留课程钩子**(但要轻,先给够价值)

## 四、每日技巧选题库(50 条,按主题分组,标注层级)

> 层级标注:【科】科普 /【技】技巧 /【转】转化。技巧型为主力。每条都是一期内容。

## 六、课程转化的埋点方法(每条内容都在做转化)

1. **每条留"课程钩子"但克制**:"这是我课里第X个技巧""想系统学的主页/扣1",给够价值再说。
2. **技巧编号 = 课程目录**:让人感觉"零散技巧背后有一套体系",自然想要完整版。
3. **每周一条 lead magnet**:技巧合集/模板包→领取要"关注公众号/进群",把看客变线索。
4. **成果/案例定期出现**:证明"学了真能用/能赚",这是付费的临门一脚。
5. **私域承接**:短视频/图文→引导领资料→公众号/企微→社群养熟→训练营/正价课。
6. **稀缺+进阶**:小技巧给"能用版",课程给"系统版/进阶版/陪跑答疑"——差异清晰,不左右手互搏。

> 关键分寸:**免费内容要真的有用到"白嫖也值",课程卖的是"系统、效率、陪伴、答疑",不是卖信息差。** 这样口碑和转化才能双赢,也彻底区别于割韭菜号。

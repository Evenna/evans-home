# 黎曼猜想 · 详细分镜脚本 v4（执行级）

成片 **4:21 / 261s / 6525 帧 @25fps**｜1920×1080｜Rec.709｜口播 1160 字
**v4 相对 v3 的增量**：①每镜有**绝对帧号**（F0000–F6525，可直接对时间线定位）；②建立了**坐标/字体/缓动 token 系统**，每个元素给精确 x,y,w,h 与字重字号，不再出现"左上角""稍大一点"；③每个动效给**起止值 + 帧区间 + 缓动曲线**；④字卡给**入帧/出帧/落点坐标**；⑤口播给**帧预算**（字×5.68 帧 + 标点停顿），并做**配速体检**（见第 5 节，24 镜超速，必须处理）；⑥自绘镜给 AE 表达式 / p5.js 代码级参数；⑦补**质检清单**，每镜可勾。

> 一句话：v3 是"这镜拍什么"，v4 是"这镜的每个像素和每一帧怎么动"。

## 0. 技术底座（所有镜共用，开新工程先照这套建）

### 0.1 帧号约定
- `F` = 帧绝对序号，`F0000` 是成片第 1 帧；`帧号 = round(秒 × 25)`。
- 每镜标 `F入–F出`，**入帧含、出帧不含**（#07 为 F0500–F0575 = 75 帧 = 3.0s）。
- 时间线设置：1920×1080 / 25fps / 丢帧关闭 / 起始时间码 00:00:00:00。

### 0.2 坐标网格（12 列 × 8 行）
- 列宽 **160px**、行高 **135px**；安全区 **x 115–1805 / y 86–994**（左右 6%、上下 8%）。
- 元素定位一律写成 `(x, y, w, h)`，锚点默认左上；居中元素标 `POS-x`。

**落点 token（字卡专用）**

| token | 锚点 | 说明 |
|---|---|---|
| POS-A | (960, 540) 中心 | 全片默认，巨字/金句 |
| POS-B | (240, 200) 左上 | 数据、编号、时间戳 |
| POS-C | (1680, 200) 右上 | 数字对比、状态 |
| POS-D | (240, 880) 左下 | 注脚、来源 |
| POS-E | (1680, 880) 右下 | 计时、计数器 |
| POS-F | (960, 780) 中偏下 | 次级金句（**与字幕带 860–994 不冲突**） |
| POS-G | (960, 960) 底带 | **禁止放字卡**，只留给字幕 |

### 0.4 缓动 token（25fps，1 帧 = 40ms）

| token | 曲线 | 时长 | 用在 |
|---|---|---|---|
| EIN | cubic-bezier(.16,1,.30,1) | 7f | 所有入场（位移/缩放/淡入） |
| EEMP | cubic-bezier(.22,1,.36,1) | 15–20f | 强调推入 |
| ESTOP | cubic-bezier(.15,.85,.15,1) | 末 5f | 数字停住 |
| ELIN | linear | 按镜 | **明确要求"匀速/没有缓动"的镜** |
| ECOUT | cubic-bezier(.33,0,.67,1) | 10f | 出场/退场 |
| HARD | — | 0f | 硬切出现/硬切转场 |
| DIS6 | 交叉叠化 | 6f | **全片仅 3 处**：#6→#7、#32→#33、#66→#67 |

**禁用**：弹跳、回弹、旋转入场、光晕、粒子飞散（#68 的 2 帧回弹是唯一例外）。

### 0.5 图层栈与声音轨

```
V1 素材/实拍   V2 图形+字卡   V3 字幕   V4 颗粒3%+暗角8%（全片一条，不断）
A1 口播(VO)   A2 BGM   A3 SFX
```
- 字幕：T7 / #FFFFFF 90% / 基线 y 960 / 居中 / ≤2 行 / 一行 ≤18 字 / 句末不带标点（问句留「？」）/ 不做卡拉 OK。
- 电平：VO -16 LUFS 峰值 -1dB；BGM -26~-18dB；SFX -20dB；**BGM 遇 VO 一律让路**。

### 0.6 口播帧预算公式
```
帧预算 = 字数 × 5.68 + 停顿
停顿：逗号 2f ｜ 顿号 2f ｜ 句号/问号 5f ｜「／」换气 10f
判定：帧预算 ≤ 镜时长×25 = ✓ 富余 ｜ 超额 0–25f = ▲ 紧 ｜ 超额 >25f = ✕ 念不完
```
> 5.68 帧/字 = 4.4 字/秒（系列统一语速）。**全片 1160 字按 4.4 字/s 需 264 秒，实际口播窗口只有 241 秒 → 24 镜超速，见第 5 节。**

### 0.7 交付规格
工程 ProRes 422 HQ 中间 → 输出 H.264 / 20Mbps / Rec.709 / AAC 320k。自绘镜一镜一工程：`S###_镜号.aep`（或 `.pde`/`.html`）。
